# Parser

The parser component is responsible for converting source code text into an Abstract Syntax Tree (AST) according to the AT language grammar.

## Architecture

The parser uses a generated Bison/Yacc parser defined in `src/syntax.ast.y` with:
- Lexical analysis handled by flex (not shown directly, but integrated)
- Grammar rules defining the language syntax
- Semantic actions that construct AST nodes

## Key Files

### src/parser.h
```cpp
#pragma once
#include "ast.h"
#include <string>

namespace at {
AstPtr parseSource(const std::string& source);
}
```

### src/parser.cpp  
Contains the parser implementation and error handling.

## Parsing Process

1. **Lexical Analysis**: Tokens are generated by the lexer (flex-generated)
2. **Syntax Analysis**: Bison parser uses grammar rules to construct AST nodes
3. **Error Reporting**: Syntax errors are reported with location information
4. **AST Construction**: Valid syntax is converted into `AstNode` structures

## Error Handling

The parser includes error reporting through:
- Location tracking for source positions  
- Error messages with line/column information
- Graceful failure handling when parsing fails

## Integration

The parser integrates with the rest of the compiler pipeline:
```cpp
at::AstPtr ast = at::parseSource(input);
// AST can then be passed to semantic analyzer, interpreter, or code generator
```
