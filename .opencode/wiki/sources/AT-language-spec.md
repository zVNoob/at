# AT Language Specification

This document describes the formal specification of the AT programming language based on the implementation in this codebase.

## Overview

AT is a statically-typed programming language with features including:
- Explicit type declarations
- Function-oriented syntax using `@` 
- Class-oriented syntax using `#`
- Template/generic support
- Operator overloading capabilities
- Module system for code organization

## Grammar Specification

The grammar is defined in `src/syntax.ast.y` and includes the following major constructs:

### Expressions
```
expr : INTEGER | DECIMAL | STRING | IDENTIFIER | IMPORT
     | expr '+' expr | expr '-' expr | expr '*' expr | expr '/' expr
     | expr '^' expr | expr '|' expr | expr '&' expr 
     | expr '?' expr ':' expr
     | expr '<' expr | expr '>' expr | expr "<=" expr | expr ">=" expr
     | expr "==" expr | expr "!=" expr
     | '-' expr %prec UNARY | '!' expr %prec UNARY
     | expr "||" expr | expr "&&" expr | expr "^^" expr
     | '(' expr ')' 
     | expr '.' IDENTIFIER
     | expr '(' expr_list ')'
     | expr '[' expr_list ']'
     | '[' expr_list ']'
     | IDENTIFIER "<{" expr_list "}>"  
     | complex_type "<{" expr_list "}>" 
     | '@' '(' func_arg_declare_list ')' '{' scope '}'
     | '@' '(' func_arg_declare_list ')' "->" '(' type ')' '{' scope '}'
     | '&' expr
```

### Types
```
type : base_type | type "::" IDENTIFIER
base_type : IDENTIFIER | complex_type
complex_type : '`' expr '`' | IDENTIFIER "<|" template_arg_list "|>"
             | anonymous_template "<|" template_arg_list "|>"
             | "@?" '(' func_arg_declare_list ')' 
             | "@?" '(' func_arg_declare_list ')' "->" '(' type ')'
             | '*' type | class
```

### Declarations
```
declare : ':' | "^:" | "~:" | "!:" | "!^:" | "!~:"
```

## Lexical Elements

### Tokens
- INTEGER: Supports hex, octal, binary notation
- DECIMAL: Supports exponent notation  
- STRING: Uses `"` as delimiters
- IMPORT: Uses `'` as delimiters (like Lua's require)
- IDENTIFIER: Allows whitespace, tab, newline, UTF8 in middle

### Operators
Special operators include:
- `::` (scope resolution)
- `<|` and `|>` (template delimiters)  
- `||`, `&&`, `^^` (logical operators)
- `<=` , `>=`, `==`, `!=` (comparison operators)
- `->` (arrow operator)
- `@?` (function pointer syntax)
- `^:` (protected visibility)
- `~:` (private visibility) 
- `!:=` (alias private)

## Example Programs

### Simple Variable Assignment
```at
x : int = 42;
y : int = x + 1;
y;
```

### Function Definition
```at
add := @(a: int, b: int) -> int {
    a + b
}
```

### Class Definition
```at
Point := # (x: int, y: int) {
    // class body
}
```

## Implementation Notes

This specification is implemented in the codebase with:
- Parser generated by Bison/Yacc
- Semantic analyzer for type checking  
- Interpreter for runtime execution
- Code generator using LLVM for compilation
